Panduan & Tutorial Penggunaan POS

Selamat datang di Aplikasi POS Kasir Modern!

Aplikasi ini dirancang cepat, intuitif, dan fleksibel untuk kebutuhan kafe/restoran Anda. Berikut adalah panduan langkah demi langkah:

1 Cara Melakukan Transaksi Kasir

  • Pilih/klik produk di katalog sebelah kanan untuk memasukkannya ke dalam keranjang.
  • Gunakan tombol + / - di keranjang untuk mengubah jumlah pesanan.
  • Masukkan Nomor Meja / Nama Pemesan atau pilih via tombol cepat Quick Select (01, 02, VIP, Takeaway).
  • Pilih metode pembayaran (CASH, QRIS, atau Transfer).
  • Klik BAYAR SEKARANG untuk memproses transaksi.

2 Cetak & Download Struk Pembayaran (JPG)

  • Setelah bayar, modal Struk Pembayaran akan otomatis terbuka.
  • Klik Cetak Struk untuk mencetak langsung via mesin printer thermal/kertas.
  • Klik Download Struk (JPG) untuk mengunduh gambar nota belanja resolusi tinggi.
  • Klik Transaksi Baru untuk mengosongkan keranjang dan bersiap menerima pelanggan berikutnya.

3 Kelola Katalog & Cetak Label Barcode

  • Buka menu Katalog Produk pada bar navigasi atas.
  • Gunakan tombol Acak SKU untuk menghasilkan kode barcode unik otomatis.
  • Di tabel produk, klik Cetak Label pada baris produk yang diinginkan.
  • Klik Download Label (JPG) untuk mengunduh gambar stiker label ber-barcode siap tempel.

4 Fitur Stok Opname (Penyesuaian Fisik)

  • Buka menu Stok Opname pada navigasi atas.
  • Atur tanggal audit/opname pada pemilih tanggal.
  • Ketik jumlah stok fisik riil yang ada di toko/gudang.
  • Pilih alasan penyesuaian (contoh: Rusak/Basi, Barang Masuk).
  • Klik Cetak Laporan Opname untuk mencetak dokumen pertanggungjawaban stok.
